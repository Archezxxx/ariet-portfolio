Flagship EdTech Engineering

AIM.EXAM: Democratizing National Exam Grading Through Computer Vision

A software-defined Optical Mark Recognition (OMR) system created to evaluate regional school olympiads and admissions tests without specialized hardware.

Applied Computer Vision De-facto standard in production

The Engineering Challenge & Solution

When teachers in regional schools scan stacks of thousands of exam sheets, the papers inevitably rotate by 5–15 degrees, shift by 10–20 pixels, or get crumpled. Standard OMR software simply misses the bubbles, causing false zeroes.

The Barrier

Conventional open-source OMR relies on rigid static bounding boxes that fail completely when sheets skew or scan lighting fluctuates.

Ariet's Algorithmic Innovation

Designed a four-stage pipeline: Hough Line fiducial alignment → 4-point homography transformation → dynamic subpixel bubble snapping (±15px tolerance) → adaptive brightness differential evaluation.

Python 3.12 OpenCV (cv2) NumPy Homography Matrix Tkinter Desktop UI Docker Compose
Real-world impact: 50,000+ student exams evaluated Accuracy rate: 99.82%
