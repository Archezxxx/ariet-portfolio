# Component and icon sources

- **Tilted Grid Hero**, Ruixen, [21st.dev](https://dev.21st.dev/@ruixen.ui/components/tilted-grid-hero). The user supplied its React component. `components/tilted-grid-hero.js` adapts its cylinder radius, measurement, negative animation delays, offscreen wrapping, and 16 image slices to the site's scoped JavaScript runtime, mounted by a React wrapper. MIT license (below).
- **Social Media**, Ravi Katiyar, [21st.dev](https://dev.21st.dev/@ravikatiyar162/components/social-media). The local Telegram icon preserves the plane contour from the [SVG used by that component](https://cdn.21st.dev/assets/mirror/05/05f6898c0c087f84c8bcf65e93721bde65abe34093045d4e9ecddbb8dc9f6a18.svg), with monochrome styling and a tighter viewBox.
- **GitHub and LinkedIn icons**: Lucide, the icon set used by [21st.dev's Team Section](https://mcp.21st.dev/@ravikatiyar162/components/team-section-1). Local SVGs from `lucide-static` 0.468.0. See `assets/icons/LUCIDE-LICENSE.txt` (ISC).
- **Manrope**, the Manrope Project Authors, Google Fonts. See `assets/fonts/OFL.txt`.

Project covers in `assets/work/` are screenshots of the portfolio's own authored HTML/CSS project illustrations. They are illustrative covers, not claimed production screenshots. No demonstration stock photographs or gradient filler from the component demo are included.

## Additional supplied components and assets

- **Background Lines**, Aceternity UI: [official registry source](https://ui.aceternity.com/registry/background-lines.json), using its 21 paths and colors twice. The named export, geometry, normal timing, and utility styling are retained; lifecycle and reduced-motion additions are documented in INTEGRATION.md. [Aceternity UI source and license](https://github.com/aceternity/aceternity-ui).
- **ATC shader:** WebGL2 equations supplied by the user in this conversation. No separate author or license was included in the supplied excerpt. The integration preserves the formula and adds lifecycle and resource handling.
- **Project artwork:** six PNG files supplied in Downloads/images.zip, including one duplicate. The five unique illustrations are used as project covers and index icons. They are not represented as production screenshots.
- **Moon cursor and trailing flower:** code-native SVG geometry authored for this portfolio.
- React, Motion, Tailwind, Vite, TypeScript, clsx, tailwind-merge, and Lucide dependencies are recorded with exact resolved versions in package-lock.json; their package distributions retain their licenses.
